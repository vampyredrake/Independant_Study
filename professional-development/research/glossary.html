Glossary Overview

This glossary defines key technical terms used throughout the portfolio. The definitions are written in concise language and support the topics studied during Weeks 1 to 4.

The terms are arranged alphabetically. Several concepts apply to more than one weekly topic because areas such as networking, databases, cyber security, web development and artificial intelligence are closely connected.

A–C D–H I–M N–S T–Z

A–C

Algorithm
A finite sequence of instructions designed to solve a problem or complete a specific computational task.
Application Programming Interface (API)
A defined set of rules that allows software systems or components to communicate with one another.
Artificial Intelligence (AI)
The field of computing concerned with developing systems capable of performing tasks that would normally require human intelligence, such as recognising patterns, interpreting language or supporting decisions.
Availability
The principle that systems, services and information should remain accessible to authorised users when they are required.
Big O Notation
A mathematical notation used to describe how the time or memory requirements of an algorithm grow as the size of its input increases.
Bias
A systematic distortion in data, system design or decision-making that may produce unfair, inaccurate or unrepresentative outcomes.
Binary Search
A search algorithm that repeatedly divides a sorted dataset into halves until the required item is found or the remaining search range becomes empty.
Browser
A software application that requests, interprets and displays web content, including HTML, CSS and JavaScript.
Cascading Style Sheets (CSS)
A stylesheet language used to control the visual appearance, layout and responsive behaviour of web pages.
CIA Triad
A cyber security model based on three core principles: confidentiality, integrity and availability.
Client
A device or software application that requests data, resources or services from another system, usually a server.
Cloud Computing
The delivery of computing resources, including processing, storage and software, through a network, usually the internet.
Confidentiality
The protection of information from unauthorised access, use or disclosure.

D–H

Database
An organised collection of data that can be stored, managed, searched and retrieved electronically.
Database Management System (DBMS)
Software used to create, maintain, secure and query a database.
Data Structure
A method of organising and storing data so that it can be accessed, processed and modified efficiently.
Domain Name System (DNS)
A distributed naming system that translates human-readable domain names into numerical IP addresses.
Encryption
The process of converting readable information into an encoded form so that it cannot be understood without the correct decryption key or method.
Ethics
Principles used to evaluate whether actions, technologies and decisions are responsible, fair and socially acceptable.
Foreign Key
A field in one database table that refers to a primary key in another table, establishing a relationship between the tables.
Hypertext Markup Language (HTML)
The standard markup language used to structure the content and semantic meaning of web pages.
Hypertext Transfer Protocol (HTTP)
An application-layer protocol used to transfer web resources between clients and servers.
Hypertext Transfer Protocol Secure (HTTPS)
The secure form of HTTP, which uses encryption to protect data exchanged between a client and server.

I–M

Infrastructure as a Service (IaaS)
A cloud service model that provides virtualised infrastructure, such as servers, storage and networking resources.
Integrity
The assurance that data remains accurate, complete and protected against unauthorised alteration.
Internet Protocol Address (IP Address)
A numerical identifier assigned to a device on a network so that data can be routed to and from it.
JavaScript
A programming language commonly used to add interactivity, validation and dynamic behaviour to web pages.
Linear Search
A search algorithm that examines each item in a dataset sequentially until the required item is found or the dataset ends.
Machine Learning (ML)
A branch of artificial intelligence in which systems identify patterns in data and use them to make predictions, classifications or decisions.

N–S

Normalisation
The process of organising a relational database to minimise data duplication and improve consistency.
Platform as a Service (PaaS)
A cloud service model that provides a managed environment for developing, testing and deploying applications without maintaining the underlying infrastructure.
Primary Key
A field, or combination of fields, that uniquely identifies each record within a database table.
Relational Database
A database that stores information in related tables and uses keys to establish connections between records.
Responsive Design
A web design approach that enables page content and layouts to adapt to different devices and screen sizes.
Secure Sockets Layer and Transport Layer Security (SSL/TLS)
Cryptographic protocols used to secure communication between clients and servers. TLS is the modern successor to SSL.
Server
A computer or software application that provides services, resources or data to requesting clients over a network.
SMART Target
A development target designed to be specific, measurable, achievable, relevant and time-bound.
Software as a Service (SaaS)
A cloud service model in which software is delivered to users over the internet without requiring local installation or infrastructure management.
Structured Query Language (SQL)
A language used to create, manage, manipulate and query data held in relational databases.
SWOT Analysis
A planning method used to evaluate strengths, weaknesses, opportunities and threats relating to a project, organisation or individual.

T–Z

Threat
Any event, action or circumstance capable of causing harm to information, systems, users or organisational operations.
Transmission Control Protocol (TCP)
A transport-layer protocol that provides reliable, ordered and error-checked delivery of data between networked systems.
Uniform Resource Locator (URL)
The address used to identify and access a resource on the World Wide Web.
User Interface (UI)
The visual and interactive elements through which a user communicates with a website, device or software application.
Virtual Machine (VM)
A software-based computer that emulates physical hardware and operates as an independent computing environment.
Vulnerability
A weakness in software, hardware, configuration or organisational procedures that could be exploited by a threat.
Web Server
Hardware or software responsible for storing, processing and delivering web content to client browsers.
