Reference List Overview

This page contains the sources cited throughout the independent study portfolio. References should follow Harvard Cite Them Right conventions and should correspond directly with the in-text citations used in each weekly section.

Each entry should include sufficient information for the reader to identify and locate the original source. Online references should include the relevant webpage address and the date on which the source was accessed.

Referencing requirement

Only sources that have been read and cited in the portfolio should be included. Every in-text citation should have a matching reference-list entry, and every reference-list entry should normally be cited within the portfolio.
