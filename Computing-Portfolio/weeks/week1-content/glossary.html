Glossary Purpose

These ten terms connect the user-interface, web infrastructure and programming-design aspects of Week 1. Each entry includes a definition and an explanation of its relevance to software development.

1. Semantic HTML

Definition HTML elements that describe the role and meaning of content rather than only its appearance.

Relevance It can improve accessibility, machine interpretation, code readability and maintenance, although semantic markup must still be supported by accessible interaction and content design (World Wide Web Consortium, 2023).

2. Responsive Design

Definition An approach in which an interface adapts to different screen sizes and input methods.

Relevance It allows the same application to work across phones, tablets and desktop computers.

3. Accessibility

Definition The practice of designing digital systems so that people with different abilities can use them.

Relevance It affects semantic structure, keyboard control, colour contrast, forms and media. WCAG 2.2 treats accessibility as a combination of perceivable, operable, understandable and robust content (World Wide Web Consortium, 2023).

4. Client

Definition Software that requests a service or resource, such as a browser or mobile application.

Relevance Understanding the client helps developers decide which work belongs in the interface and which should be handled by the server.

5. Server

Definition A computer or software process that receives requests and provides data, processing or other services.

Relevance Servers contain application logic, authentication, APIs and access to stored information.

6. DNS

Definition The Domain Name System that maps human-readable domain names to IP addresses.

Relevance It allows users to reach websites without remembering numerical network addresses.

7. HTTP

Definition The application protocol used to structure web requests and responses.

Relevance Methods, status codes and headers allow clients and servers to communicate consistently under shared protocol semantics (Fielding, Nottingham and Reschke, 2022).

8. HTTPS

Definition HTTP communication protected by Transport Layer Security.

Relevance It protects information in transit and helps confirm the identity of the server, although it does not guarantee that the application itself is secure (Rescorla, 2018).

9. Encapsulation

Definition Restricting direct access to an object's internal state through a controlled interface.

Relevance It reduces accidental changes and helps objects maintain valid data.

10. Concurrency

Definition The management of multiple tasks whose execution overlaps.

Relevance It supports responsive applications and web servers, but requires careful control of shared resources.
