Learning Types, Applications, Algorithms and Limitations

Overview

Machine learning is a branch of artificial intelligence in which computational models identify patterns from data. Instead of every decision being defined through fixed programming rules, a model is trained to make predictions, classifications or decisions based on previous examples or feedback (Mitchell, 1997). The resulting behaviour remains dependent on the selected objective, data and evaluation process; learning does not make the model independent of human design choices.

The three main learning categories examined here are supervised learning, unsupervised learning and reinforcement learning. Each approach uses a different form of training information and is suitable for different types of problem.

Selecting an approach should not be based only on which technique appears most advanced. The decision should also consider data availability, interpretability, computing cost, ethical risk and the consequences of an incorrect prediction. A simpler baseline can be professionally preferable when it achieves comparable performance and is easier to validate, explain and maintain (Géron, 2023).

Comparison of Learning Types

Learning Type How It Works Appropriate Applications Main Limitations
Supervised learning The model learns from labelled examples. Each training example includes input data and a known target output. Spam filtering, fraud detection, medical diagnosis support, house-price prediction, image classification and demand forecasting. Requires sufficient labelled data. Labels can be expensive, incorrect or biased. Performance may decline when real-world data differs from the training data.
Unsupervised learning The model identifies patterns, similarities or structures in data that does not contain known target labels. Customer segmentation, anomaly detection, document grouping, exploratory data analysis and dimensionality reduction. Results can be difficult to evaluate because there may be no correct answer. Discovered groups may not have a meaningful practical interpretation.
Reinforcement learning An agent interacts with an environment, selects actions and receives rewards or penalties. It learns a policy intended to maximise long-term reward. Robotics, game-playing systems, traffic-signal control, resource allocation, route planning and automated industrial control. Training may require many interactions and substantial computing resources. Poor reward design can produce unsafe or unintended behaviour.

Supervised Learning

Supervised learning is used when historical data contains known outcomes. The model compares its predictions with those outcomes and adjusts its internal parameters to reduce error.

Supervised learning commonly supports two categories of task:

  • Regression: predicting a continuous numerical value, such as temperature, sales demand or property price.
  • Classification: predicting a class or category, such as fraudulent or legitimate, positive or negative, and spam or not spam.

Appropriate Application

A bank could use supervised classification to identify potentially fraudulent transactions. Historical transactions would be labelled as fraudulent or legitimate. Features could include transaction value, location, time, device and previous account behaviour.

Benefits

  • Performance can be measured against known answers.
  • The model can make predictions for new examples.
  • It supports both numerical forecasting and classification.
  • Several established evaluation metrics are available.

Limitations

Supervised learning depends heavily on label quality. If human decisions in the historical data were inconsistent or unfair, the model may reproduce those weaknesses. This means that validation against historical labels can confirm consistency with the past without demonstrating that the underlying decision process was fair or correct.

The model may also learn relationships that are statistically useful but not appropriate. For example, a variable may act as a proxy for a protected characteristic. Ethical evaluation is therefore required alongside technical testing.

Unsupervised Learning

Unsupervised learning is used when data does not include known output labels. The model attempts to identify structure within the available observations.

One common unsupervised task is clustering. A clustering algorithm groups examples that appear similar according to the selected features and distance measurement.

Appropriate Application

A retail organisation could analyse customer purchase histories and group customers according to buying behaviour. The resulting clusters might identify frequent customers, occasional high-value customers or customers focused on particular product types.

Benefits

  • Does not require expensive manual labels.
  • Can reveal patterns that were not previously known.
  • Supports exploratory analysis before a supervised model is developed.
  • Can help identify unusual observations or possible anomalies.

Limitations

A mathematical cluster is not automatically a useful business category. Analysts must interpret whether the identified pattern is meaningful and whether it supports an appropriate organisational decision.

Results may also change when different features, scaling methods or numbers of clusters are selected. This makes evaluation less direct than supervised learning. Internal cluster metrics can measure mathematical separation, but domain review is still required to establish whether the groups are meaningful and actionable.

Reinforcement Learning

Reinforcement learning focuses on sequential decision-making. An agent observes an environment, performs an action and receives feedback through a reward or penalty.

The agent must balance exploitation and exploration. Exploitation uses actions that currently appear effective, while exploration tests alternatives that may produce better future results.

Appropriate Application

A warehouse robot could use reinforcement learning to identify efficient routes between storage locations. It may receive a positive reward for completing a delivery and penalties for collisions, delays or unnecessary movement.

Benefits

  • Can learn strategies for complex sequential problems.
  • Can adapt decisions according to environmental feedback.
  • May discover strategies that are difficult to define using fixed programming rules.
  • Supports optimisation over a sequence of actions rather than one isolated prediction.

Limitations

Reinforcement learning can be expensive because the agent may require a very large number of interactions. Training directly in a real environment may also be unsafe, impractical or costly.

Reward design is a significant risk. An agent may maximise the numerical reward in an unexpected way that does not match the real organisational objective. Testing in simulation reduces immediate harm but cannot guarantee safe transfer to a changing real environment (Russell and Norvig, 2021).

Machine Learning Algorithm Comparison

Approach Main Strengths Main Limitations Suitable Applications
Linear regression Simple, efficient and relatively easy to interpret. Shows the estimated relationship between inputs and a numerical target. Assumes an approximately linear relationship. Can be affected by extreme values and may underfit complex data. Sales forecasting, property-price estimation, demand prediction and numerical trend analysis.
Logistic regression Efficient classification, produces probabilities and can be easier to explain than more complex models. May struggle with complex non-linear relationships unless features are transformed. Fraud prediction, medical-risk classification, customer response and binary classification.
Decision tree Easy to visualise, handles numerical and categorical information and can model non-linear relationships. A deep tree can overfit. Small changes in the training data may create a different tree. Decision support, customer classification, eligibility assessment and rule discovery.
Support vector machine Can perform well with high-dimensional data and aims to create a strong separating boundary. Can be slow on very large datasets and may be difficult to interpret when complex kernels are used. Text classification, image classification and datasets containing many features.
Neural network Can represent highly complex relationships and process unstructured data such as images, audio and text. Often requires large datasets, high computing resources and extensive tuning. Decisions may be difficult to explain. Computer vision, speech recognition, language processing and complex pattern recognition.

Linear Regression

Linear regression predicts a continuous numerical output. A simple linear model represents the relationship between an input variable and a target using a straight line. 

predicted value = intercept + coefficient × input

Multiple linear regression extends this approach by using several input variables. For example, a property-price model might use floor area, number of rooms and location.

Evaluation

Linear regression is useful when a clear baseline and understandable coefficients are required. It is less appropriate when relationships are strongly non-linear or when the effect of one feature depends heavily on another.

Logistic Regression

Logistic regression is primarily used for classification. It estimates the probability that an example belongs to a particular class.

A threshold can convert the probability into a class. For example, a transaction with a predicted fraud probability above a selected threshold may be sent for additional review.

Evaluation

Logistic regression can provide a strong baseline because it is efficient and its coefficients can be examined. However, its apparent simplicity does not guarantee fairness or correctness. The result still depends on training data, feature design and the decision threshold.

Decision Trees

A decision tree makes predictions through a sequence of conditions. Each internal node tests a feature, each branch represents an outcome and each leaf provides a final prediction. 

Is transaction value greater than £1,000?
├── No  → lower-risk branch
└── Yes
    ├── New device? Yes → manual review
    └── New device? No  → further checks

Evaluation

Decision trees are attractive where stakeholders need to follow the reasoning behind a prediction. They can still become difficult to interpret when they contain many levels.

Limiting depth, requiring a minimum number of examples at each leaf and pruning unnecessary branches can reduce overfitting.

Support Vector Machines

A support vector machine attempts to identify a boundary that separates classes while maximising the margin between the closest examples.

Kernel functions allow the algorithm to represent non-linear boundaries without explicitly transforming every example into a new set of dimensions.

Evaluation

Support vector machines can be effective for moderate-sized datasets containing many features. They are less suitable where very large datasets require rapid training or where detailed explanation is essential.

Neural Networks

A neural network contains layers of connected artificial neurons. Input values pass through weighted connections, and the resulting values are transformed by activation functions.

During training, the network's weights are adjusted to reduce prediction error. Networks containing many hidden layers are described as deep neural networks.

Evaluation

Neural networks are appropriate for complex unstructured data, including images, speech and natural language. They may achieve stronger predictive results than simpler methods, but this benefit should be weighed against training cost, energy use, maintenance and reduced explainability.

Model Evaluation

Training, Validation and Testing

A dataset is normally divided so that model performance is assessed using information that was not used during training.

  • Training data is used to adjust model parameters.
  • Validation data supports model selection and hyperparameter tuning.
  • Test data provides a final estimate of performance on unseen data.

Repeatedly changing a model according to test-set results can make the test data part of the development process. This produces an unreliable estimate of generalisation. Cross-validation can improve the use of limited data, but it does not correct unrepresentative sampling or leakage between training and evaluation data (Géron, 2023).

Classification Metrics

Metric Meaning When It Is Important
Accuracy The proportion of all predictions that were correct. Useful where classes are balanced and errors have similar consequences.
Precision The proportion of positive predictions that were correct. Important where false positive results create significant cost or harm.
Recall The proportion of actual positive cases that were detected. Important where missing a positive case is particularly harmful.
F1 score A combined measure based on precision and recall. Useful where a balance between precision and recall is required.

Accuracy Is Not Always Sufficient

A fraud dataset may contain 99 legitimate transactions for every fraudulent transaction. A model that predicts every transaction as legitimate would achieve 99 percent accuracy while detecting no fraud.

This example demonstrates why metrics must be chosen according to the purpose of the system and the practical consequences of each type of error. Thresholds should also be reviewed after deployment because class frequencies, user behaviour and the cost of errors can change over time (scikit-learn Developers, 2026).

Overfitting and Underfitting

Overfitting

Overfitting occurs when a model represents the training data too closely, including noise and unusual examples. Training performance may be high while performance on new data is weak.

Underfitting

Underfitting occurs when the model is too simple to represent the main relationships in the data. Performance is poor on both training and unseen examples.

Possible Controls

  • collect more representative data;
  • use cross-validation;
  • reduce unnecessary model complexity;
  • apply regularisation;
  • remove irrelevant features;
  • use early stopping when training neural networks.

Practical Selection Scenarios

Scenario 1: Predicting Monthly Sales

Linear regression may provide an appropriate starting point because the output is numerical and stakeholders may need to understand the relationship between variables and predicted sales.

Scenario 2: Identifying Spam Email

Logistic regression, a support vector machine or a neural network could be used. Logistic regression may provide a useful interpretable baseline, while more complex methods may improve performance with sufficiently large datasets.

Scenario 3: Segmenting Customers

Unsupervised clustering would be appropriate because the organisation may not already possess agreed customer categories. The resulting groups would still require human interpretation.

Scenario 4: Controlling a Warehouse Robot

Reinforcement learning could support sequential movement decisions. Training should initially take place in a simulation because uncontrolled exploration in a physical environment could damage equipment or create safety risks.

Scenario 5: Supporting a Medical Decision

A model used in healthcare should be selected according to both predictive performance and explainability. Human oversight, testing across patient groups and clear accountability would be essential.

Critical Evaluation

Supervised learning is effective when reliable labelled data exists, but it may reproduce weaknesses in historical decisions. Unsupervised learning can reveal unexpected patterns, although the output does not automatically have practical meaning. Reinforcement learning is suitable for sequential decisions but creates additional challenges involving reward design, safety and computing cost.

Linear and logistic regression are useful where simplicity, speed and interpretation are priorities. Decision trees can provide understandable rules but are vulnerable to overfitting. Support vector machines can perform effectively with high-dimensional data, while neural networks are suited to complex unstructured information.

No algorithm is consistently best for every problem. A professional selection process should compare several models using representative data and appropriate metrics. It should also evaluate privacy, fairness, explainability, security and operational maintenance.

The most technically accurate model may not be the most appropriate organisational choice. A slightly less accurate model may be preferable where it is easier to explain, cheaper to operate and less likely to create unacceptable harm.
