Critical Reflection

Two major cybersecurity risks facing modern organisations are cloud identity compromise and software supply-chain compromise. I selected these risks because organisations increasingly depend on cloud accounts and third-party software rather than operating isolated systems.

Cloud identity compromise is serious because a valid account can allow an attacker to appear legitimate. Stolen passwords, session tokens, OAuth permissions or excessive service-account privileges may provide access to email, storage and administrative systems. I initially viewed multifactor authentication as a largely complete response to password theft. Further study showed that consent phishing, session theft and repeated approval prompts can bypass weaker implementations. Stronger controls include phishing-resistant authentication, conditional access, short-lived credentials, least privilege and continuous monitoring. These measures align with a layered risk-management approach rather than dependence on one preventive control (National Institute of Standards and Technology, 2024).

Software supply-chain compromise is also significant because organisations trust code, packages and updates produced by other parties. A malicious dependency or compromised build process may enter through an apparently legitimate development activity. Traditional antivirus may be less effective when software is signed or executed by trusted tools. Dependency pinning, code signing, software bills of materials, restricted build environments and package-source verification improve assurance. However, an SBOM provides transparency rather than proof of security, and code signing proves origin and integrity rather than benign behaviour (Cybersecurity and Infrastructure Security Agency, 2021).

My main conclusion is that both risks exploit trust rather than only technical vulnerabilities. Effective defence depends on limiting trust, verifying identities and monitoring activity after access has been granted. I also recognise that additional controls create operational costs and can obstruct legitimate work when they are poorly designed. Security decisions must therefore be proportionate, testable and reviewed against changing threats. No single control is sufficient; organisations need layered prevention, detection, response and recovery measures supported by clear accountability.

Reflection Summary

Risk one: cloud identity and access compromise.

Risk two: software supply-chain compromise.

Main conclusion: modern attacks often exploit trusted identities, applications and suppliers, so controls must continue after initial authentication.
