Sources for the Threat Analysis

The threat analysis draws on AWS guidance for instance metadata, Microsoft guidance for application consent, CISA guidance for software bills of materials, NIST risk management guidance and the TLS standard. These sources were selected because they provide primary technical or government guidance relevant to the controls discussed.

Source Evaluation

Academic books provide established explanations of network models, protocols and cryptographic principles. Standards provide authoritative technical definitions, while government and professional guidance reflects current security practice.

Vendor documentation is useful for explaining how specific cloud services operate, but it should be considered alongside independent security sources because each provider describes its own products and responsibilities.

Referencing Checklist

  • Full URLs are included for online sources.
  • Access dates are included for online sources.
  • In-text citations must match this reference list.
  • Use the university's required Harvard format consistently.
  • Check publication dates and edition numbers.
